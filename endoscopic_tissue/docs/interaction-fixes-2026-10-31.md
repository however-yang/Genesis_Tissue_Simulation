# 交互修复实验与验收（2026-10-31）

本轮在 dev 上进行隔离实验。默认启动代码、材料参数、摩擦系数以及三个受保护 DLL 均未替换。已有松夹接触修复显著改善穿入和异常耗时，但普通交互的性能验收仍未通过，不能标记为可采用版本。R18数值精度改动也未通过纯摩擦耗时检查，薄壁残连与弱夹取仍有未解决项。

材料与接触的硬性条件保持：相同网格、时间步、子步数、迭代预算、体积保护、材料刚度和阻尼。纯摩擦测试使用 contact_model=1、静摩擦0.6、动摩擦0.4；切除参考流程保持原来的 contact_model=2。后者有辅助夹持点，不能当成纯摩擦夹取成功的证据。

**切除后真正松夹。** 肾脏算例含102,710个材料节点、121,260个活动节点、354,200个总网格节点，网格间距1毫米，时间步1/30秒，每步3个子步，E=15kPa。完整轨迹包括接近、闭合、提拉、两次切除、撤刀、侧拉、真正打开夹爪和撤离。夹爪松开后的77帧逐帧保存几何状态。下文穿入量是游离块表面顶点位于主体内部时到主体表面的最大距离；逐帧顶点检查覆盖全部保存的游离块顶点，但不等于所有三角面之间的连续相交证明。

原始接触修正会被后续材料/体积处理拉回，而且对远离组织的表面也产生了错误接触；原始游离组织检测的几何查询还造成秒级耗时。实验将双方接触纳入同一个材料目标，保留预测接触，并在材料迭代中重新检查实际位置。接触双方承担成对作用，原有体积保护仍然执行。空间树和完全相同的嵌入点查询共享降低几何检测开销。去重仅共享查询结果；新接触模型中各条组织间接触仍保留各自的面积权重、刚度、阻尼及身份。原有材料、夹爪和刀刃参数不变，游离组织之间的接触求解方式本身是这次修复的改动。

**薄壁残连。** 用材料节点和全部活动节点分别搜索从被夹起薄壁到固定底座的连接，排除预期保留的左侧附着部分，避免只看外观或只检查体材料而漏掉表面支撑层。原失败录像确有材料和支撑层连接。原始源码诊断版中，将第三剪沿刀轴退短3毫米后，两类连接都保留；实际开刀、向前送刀4毫米并重新闭合后，两类连接都断开。R16对同一路径也得到相同的连接变化。该对照说明刀尖实际覆盖不足可以导致残连，不能用扩大剪切范围或直接删边来伪造“剪干净”。

这些带诊断的原始源码版本来自受保护的 native/vendor，不能把它们与当前 bin-contact-groups31 的二进制完全等同。当前 bin-contact-groups31 的同路径1470步已完成：第三剪后材料及全部活动节点到基座的路径都已消失，第四剪后也保持断开；而R16及原始源码诊断对照在第三剪后仍保留连接。这次配对存在实际剪切响应差异，尚不能将其归为已修复或证明与当前基线等效；R18同一路径同样在第三剪后保留10节点材料路径和21节点全部活动节点路径，实际补剪后两者均断开；1470步完成，刀体最大重叠0.1961毫米，无效四面体为0。标准薄壁路径另完成1185步，最大刀体重叠0.1837毫米，无效四面体为0。同一当前基线DLL的重复1470步随后也在第三剪后保留10节点材料路径及21节点全部活动节点路径，补剪后均断开；最大刀体重叠0.1930毫米、无效四面体为0。两次当前基线最终切断边数为130/104，R18为109。第三剪是否断连存在运行差异，不能将单次差异直接归因于R18，也不能据此证明等效或已修复；较短刀程的覆盖稳定性仍未通过。薄壁原记录还有一个仍连接主体的支撑节点位移约71.9毫米；它不是合法游离块的刚体下落。多次重跑尚未复现该尖峰，因此不能宣布已经修复。

**局部数值精度。** 补剪时保存的同一矩阵与梯度中，原单精度伴随矩阵求逆产生16.9278%的相对线性残差，解相对双精度参考偏差4.6773%。独立CUDA测试中的受保护双精度LDLT得到0.002387%的残差和约3.50e-8的相对解误差；输出仍存为单精度。从R18实际源码提取且逐字核对的结构已通过CUDA回归，覆盖2个真实矩阵和896个旋转正定矩阵。合成矩阵的最大相对解误差约0.309%；高条件数下输出仍为单精度，不能把真实案例的0.002387%残差推广到所有矩阵。此结果证明存在局部数值误差，但尚不能证明它就是71.9毫米尖峰的唯一原因。
