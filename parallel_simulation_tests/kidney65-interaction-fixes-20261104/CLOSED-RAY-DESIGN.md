# 已认证闭合表面的有向射线加速

基线：r23-production；保留原 FEM/材料目标、dt、3 子步、迭代预算、接触刚度、摩擦、面积积分、刀刃法则、CCD 见证与重叠恢复。r24 几何/组装拆分未显示稳定收益，不启用。

## 依据与范围

闭合且一致定向的三角形 2-cycle，其绕数是有向射线穿越次数。开口三角片的广义绕数不满足此替换条件，因此继续使用原积分和原含糊区间全量回退。
参考原理：[Jacobson et al. 2013](https://igl.ethz.ch/projects/winding-number/)、[Woop et al. 2013](https://jcgt.org/published/0002/01/05/paper.pdf)。这里只使用公开原理，自行实现有向计数及回退；不声称未经证明的临床真实性。

## 证书

按完整嵌入绑定（id/count、weight、offset 的逐字位）确定顶点，不使用位置容差焊接。GPU 64 位哈希只用于排序，同哈希组必须逐字位验证，否则整张表面退回原算法。边用两个规范顶点号精确排序，必须恰好两个方向相反、同组件的入射面。忽略的无效跨组件三角形与原绕数过滤一致。

证书在初始发现/接触 pass 的树排序前重建。每次非线性 refresh 都重拟合当前与 swept 包围盒；它们复用同一子步内不变的嵌入绑定/组件所证明的闭合性。新的切割、表面绑定或新子步重新建证书。

## 数值边界

用 double 做射线剪切投影和带保守间隔的边函数。边/顶点命中、原点在表面、退化或数值不确定时，该 query 保留原广义绕数积分。采用有向次数而非奇偶性，保留嵌套和反向闭合面的整数度。CCD、最近见证、实际法向及所有约束项保持原路径。

## 状态分类

- `d_fragmentClosedCanonical`：临时规范编号，归入原生分配清单并绑定快照指针。
- 原 keys/order/sortTemp：复用既有临时区，容量增加到 3×面数；随后原 Morton 排序覆盖它们，查询仍读原空间树。
- `g_fragmentClosedCertificate`：可重算设备标记；每次首次发现/接触查询前完整重建，refresh 只在同一次绑定/组件范围内读。边界快照恢复后下一步同样先重建；必须由恢复/拓扑回退测试验证。
- probe stats：只用于独立探针，在每次 probe 前清零；不参与物理。

## 验证门槛

1. CPU 与 GPU 精确证书相同；四组真实状态中整数绕数、见证、法向、深度等 18 个决定字段逐位一致，诊断角度与访问次数允许算法不同。
2. 开口、反向、非流形、射线命中边/顶点和原点在表面均须安全回退，与基线决定相同。
3. 正常路径完整切割、真实松夹/放下/换抓/抬起、20 次八步同快照续跑、预切/切后恢复、完整归档往返和训练 API 必须通过。
4. 同机 A100 第二张、相同配置和完整录像/无录像耗时对照。不把 kernel 微基准等同于整步帧率；默认只在全部物理/性能门槛通过后更换。
