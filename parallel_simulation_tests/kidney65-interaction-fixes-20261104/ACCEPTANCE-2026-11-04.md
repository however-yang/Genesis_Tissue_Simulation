## 性能保护：仍未通过

以下是同一台机器上的 LCS_Step 墙钟耗时，排除初始化和额外快照复跑。Python 观测读回、几何检查、渲染、录像不在这些 native 数值中。p95 耗时也不等于最低帧率。

| 平台/运行 | 原 1110 步平均 | 原流程 p95 | 真松夹/换抓平均 |
|---|---:|---:|---:|
| Windows RTX 3090 旧基线 | 30.791 ms / 32.48 Hz | 34.928 ms | 未作同路线基线验收 |
| Windows r12（十次复跑失败） | 32.071 ms / 31.18 Hz | 35.263 ms | 39.998 ms / 25.00 Hz |
| A100 第二张：同轮新基线 baseline-current-a2 | 33.143 ms / 30.17 Hz | 38.208 ms | 旧版存在交互失败 |
| A100 第二张：r21-production 完整录像 | 34.552 ms / 28.94 Hz | 39.076 ms | 44.038 ms / 22.71 Hz |
| A100 第二张：r23 缓存查询完整录像 | 34.546 ms / 28.95 Hz | 38.888 ms | 42.940 ms / 23.29 Hz |

r21 原流程比同轮基线多约 1.41 ms（4.25%）；自由块接触阶段仍超过 33.33 ms。**不能声称已经全阶段稳定 30 Hz，也不满足原先的“不降低帧率后替换默认”条件。** 原基线在本轮还复现了 59.64 N 反力尖峰及诊断失败，不能把其速度等同于已经正确处理自由块接触的速度。

r12 的直接内核分段诊断表明：放下阶段 loop contact discovery 约 10.14 ms，regrasp_close 约 13.30 ms；预测/恢复查询约 6.60–7.32 ms，粗模态约 6.40–6.98 ms。诊断路径会增加同步开销，这些数值只用于定位热点，不能直接与生产 wall-time 相加或当作生产 FPS。
