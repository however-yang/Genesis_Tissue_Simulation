# 松夹效率、纯摩擦与剩余训练验收

当前授权：继续在第二张 A100 逐项修复；每项同库耗时和完整交互录像；真实性/帧率不过不替换默认，全部通过后再推送。既有代码点 dca657f，r23-production 是本轮正确性候选基线。

1. 性能：先验证几何查询与约束组装拆分。当前 kernel 同时包含 warp 几何遍历及 lane 0 的 32 项绑定数组，存在高局部内存负担。两段之间不改变位置，所有原始面积、刚度、CCD、绕数回退和约束均保留。对照逐位几何记录、GPU 资源和正常 wall time；完整 20 次续跑及完整松夹/换抓录像。
2. 可替代方向：小型 BVH 缓存已有小幅收益；几何分类替换（例如射线代替绕数）会改变开口切面语义，暂不采用。先减少数据/执行耦合，不减约束或迭代。
3. 纯摩擦：显式 contact_model=1、零辅助锚点；从可咬住的已知状态、无摩擦负对照和多方向牵拉开始。确认滑脱与夹持失败来源，再完成剂量/重抓测试，不把 mode=2 视频充作证据。
4. 训练验收：以冻结 S15–S17 清单核对同一最终候选。补齐接触前/起切/挤压/换抓分叉、拓扑回退重剪、缓存和资源；核对 S16 撕裂/过载脱夹、遥测、S17 参数/几何留出，继承历史失败而不拼凑不同库的通过。
5. 每一项保留独立 build/outputs/source；GPU 空闲后执行，不中止其他任务、不安装依赖、不改网络。只有物理、完整录像和性能均通过才考虑默认替换与 GitHub 上传。
