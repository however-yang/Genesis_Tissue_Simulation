## 版本与复现边界

`docs/remaining-work-2026-11-03.md` 中的 Windows `dev/a548a53` 是历史审计上下文，不是本归档的父提交。各报告中的库 SHA 是对应实验的版本依据，不能交叉替代。

脚本按原测试版本保存，包含这台服务器的绝对路径、GPU UUID、CPU 编号及历史结果位置。原生源码、参数和脚本已归档，但运行时依赖、编译库、资源包、完整数据、录像、快照、CUPTI trace 和原始日志不在 Git 中。报告指向这些原始证据的链接仅在服务器部署目录有效，不能将缺少原始证据的全新克隆称为可一键复现。迁移前核对路径、依赖、资产、库哈希、GPU 可用性和新的输出目录；不要直接启动历史自动队列。

`../runs/` 保留先前隔离实验的源码，以满足本轮诊断对 R3、R8 等代码的依赖。它不是默认运行入口。`r9-vertex-cone/source/` 和补丁只保留被拒绝候选的精确源码，不替换正式求解器。

本次归档没有重新运行 GPU 实验。发布前仅核对源码哈希、Python 语法和 11 项 CPU 回归；详见 `publication-validation.json`。
