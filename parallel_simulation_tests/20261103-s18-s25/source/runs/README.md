# 服务器隔离实验源码归档

此目录从部署目录 `runs/` 选择性保存源代码和构建配方。原始实验数据、录像、快照、二进制和运行日志保留在服务器，不上传 Git。

这些目录包含不同实验版本和失败候选，不是统一通过验收的求解器。R3 的完整任务仍有质量缺口；R6–R9 不采用。具体证据和边界见 `../docs/remaining-work-2026-11-03.md` 与 `../parallel_simulation_tests/` 报告。

不少历史脚本含固定服务器路径或启动队列的顶层代码，不能批量导入或直接重跑。此目录的存在不改变默认 `endoscopic_tissue/` 源码。
