# 材料与接触的下一轮独立实验

起点 dev fbcaf71dc0eec30e00b55d46bf5ae0eddac271b3。用户已授权逐项尝试算法，未验证不替换默认；上一轮联合粗模态两版明确不采用。

## 已核对的边界

- 材料四面体已在建立时过滤非活动 cell；不把重复压缩当成新算法。
- 当前 PCG 受载3次/自由7次，保留预算、材料参数、细层/工具修正、接触和切割。
- 基线约44ms核心，旧多重网格迭代段约5.36ms；不能只删粗模态期待33Hz。

## 本轮顺序

1. 材料实验：用加性多层预条件器替代每次 PCG 的乘性 V(1,1)。保持 Galerkin 算子、连通分量聚合、最粗层逆、.7对角权重；各层限制原残差，累加对角和粗层修正，省去 V-cycle 中 A*x 的反复遍历。保持PCG3/7与原目标/可行性线搜索。每个细层自由度仍保留。数值递推变化可能影响有限迭代交互，不能预先宣称等价。
2. 数值探针：冻结真实层次与CG掩码，在独立scratch上计算随机输入，导出层次/对角/最粗层逆，Python双精度独立递归核验；检查有限值、对称性、正二次型及固定节点为零。随后正常Graph ABBA各1110步、真实基线/候选各1111帧和完整并排视频。
3. 接触实验单独基于原基线：保守分组 AABB 粗筛，在每次表面点更新后更新分组界，窄阶段保留原查询体/旧接触预载/旋转保护。冻结输入比较全部有效接触记录、degree与成员，不准丢查询；通过后再ABBA和完整候选录像。
4. 所有构建用独立bin目录；两项不叠加。未通过保留补丁证据并恢复生产源，只有性能与质量均有依据才进入多场景采用级重复。

参考加性层次公式来自 NGSolve 官方教程：https://docu.ngsolve.org/latest/i-tutorials/unit-2.1.3-multigrid/multigrid.html 。本项目为切割分量块对角的自定义变体，不将教程椭圆算例的收敛界自动套用到软组织接触。
