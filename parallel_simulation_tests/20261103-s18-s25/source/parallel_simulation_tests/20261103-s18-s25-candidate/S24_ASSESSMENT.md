# S24 抓钳朝向评估

当前 11 维动作仅包含抓钳位置/开合与剪刀位置/方向/开合；抓钳 `jaw_axis`、`jaw_normal` 来自 Settings。原生 Grasper 命令和接触几何已经接受方向，但这不等于训练接口和带载旋转接触已通过验证。

1. **接触能否抓住**：需要在固定材料/接触/子步下扫描偏航、俯仰，分别检查两侧载荷、见证点保持、滑移和切割期间保持。尤其纯摩擦夹持尚无充分验证。现有网格几何支持旋转，不能替代受载测试。
2. **快照**：原生状态归档已保存 `g_tool`、`g_toolFrom`、抓持参数与接触缓存，但 Python 动作历史、朝向限速器、观测重建、准备脚本和控制器状态仍须纳入版本化合同。恢复时必须验证接触摩擦基与历史方向，不能只比较节点位置。
3. **限速**：新建版本化动作合同（保留现有 11 维合同）；优先两维偏航/俯仰增量，通过正交旋转生成 axis/normal，防止独立向量退化。角速度/角加速度上限应通过带载扫描确定，不在此文件捏造“已安全”的数值。新动作与旧策略的 SHA/合同必须隔离。

本需求只要求先评估，因此本轮没有扩大动作维度。如果 S18 固定朝向通过 C1–C5，可暂缓；否则先小角度、无切割、单姿态快照验证，再拓展带载换抓。实现前置依赖仍为换抓后继续剪和纯摩擦保持能力。

对“是否符合真实带齿抓钳”的回答：当前代码与 T0 结果不足以证明。需要真实器械的钳口形状、压力/闭合标定和组织滑移数据；不能把库仑摩擦系数调到某个值就称为真实标定。
