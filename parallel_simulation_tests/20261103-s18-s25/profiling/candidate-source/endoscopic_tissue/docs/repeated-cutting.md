# 多刀向与重复切割记录

本轮保留同一次夹持，先拉伸有厚度组织，再连续进刀、短退刀、组织内停顿、完整退刀。刀刃绕原生 Y 轴旋转，显示和碰撞采用同一方向。每组使用独立环境；不代表在一次夹持中动态旋转刀片。

## 已定位的问题与修改

- 旧实现按另一侧节点的当前位置决定切面绕序。分离节点移动后会翻转切面；现改为固定材料边的拓扑绕序。
- 外表面与切面会生成共用同一组材料顶点、方向相反的内部三角形。重建时按顶点标签抵消这些面，不焊接位置接近的两侧裂面。外表面也跳过零面积半面。
- 切割发生在物理子步中，新切面原先到下一帧才绑定碰撞。现检测切割修订，在下一子步前更新表面绑定。
- 已失去全部体单元的小组件仍进入体积材料与切割阻力求解，诊断记录发现其单个子步出现厘米级跳变。现按当前连通组件检查体单元支撑：无支撑小组件使用惯性预测、剩余弹性边和器械碰撞，保留质量、重力与真实节点。
- 碎片对组织的接触采用嵌入表面和质量加权修正。褶皱处最近三角形的法线不足以判断内外，增加整体绕数与有向射线的重叠恢复，避免陷在细小重叠层中。新分离组件可能在预测前已重叠，因此在主步进预测前先修正重叠并去除入射法向速度，保留切向速度。逐子步日志进一步证实，若每次迭代用已修正的位置重新计算恢复方向，会交替把碎片推向组织两侧；现固定一次求解中的原始入射方向。
- 重复加深会使裂口前缘两角共享材料顶点，固定对角线剖分让四个切面共用一条内部边。现根据共享角选择另一条对角线，保留裂口两侧独立的内部边。
- 刀背接触原先只保留完整体素的接触侧。切面重建并重新排列三角形后，会丢失薄刀背原来的接触侧；新增按体素、断边掩码、局部组件身份匹配的接触缓存，不把裂口两侧混在一起。重建后的材料松弛迭代同时刷新刀背接触区域，处理回弹切口接触点的变化。

## 验收范围

逐帧检查有限数值、60 mm 操作范围、夹持保留、刀背/刀杆最大重叠 <= 0.2 mm、整个重建表面无零面积三角形、断边不恢复、退刀/停顿不新增切割以及活体单元体积比 >= 0.149。阶段保存点另外检查位置焊接后的边界、非流形边、重复面和绕序。独立 audit_repeated 检出异常时返回非零退出码；12 项 CPU 检查包含人为破洞、翻面和重复面的反例。超过 0.05 mm 的刀背重叠峰值自动保存原始状态以供诊断。

网格为 2 x 0.5 x 2 mm，仿真步长 1/30 秒，每帧 3 个物理子步。录像按仿真时间播放，属于离线录制，不是实时性能证明。

## 运行

在 D:\Simulation\genesis-world 下，输出目录需尚不存在：

~~~bat
D:\develop\anaconda3\envs\genesis_world\python.exe -m endoscopic_tissue.stress_cutting --yaw 45 --pattern deepen --video --render-every 2 --output endoscopic_tissue\outputs\my-repeat-test
D:\develop\anaconda3\envs\genesis_world\python.exe -m endoscopic_tissue.audit_repeated endoscopic_tissue\outputs\my-repeat-test
~~~

pattern 的 deepen 是三次加深；parallel 是相邻位置；retrace 是沿旧路径反复进入。每次退刀都包含组织内部停顿与完全离开后的停顿。支持 --yaw、--cycles、--substeps、--dll 和诊断用 --debug-cut。

## 适用边界

这是当前网格、材料、夹持位置和规定走刀路径下的验证。没有实现任意相交切口的通用体网格重划分。新接触主要针对独立分离组件；同一连通组织内部的全面自碰撞、微小碎片的体积精度仍未建立。无体单元残片与受导引器械的接触采用运动边界，不能作为微小碎片反馈力的标定结果。

失败记录保留在 outputs/repeated-cutting 的 baseline、fragment、winding、overlap、particle、diagnostic、precontact 与 final 目录。目录名不是验收状态：早期 precontact/final 版本存在主步进未调用前置修正的遗漏，部分测试仍失败，不能据目录名当作最终通过。最终结果以各次 report.json 和 checkpoint-audit.json 为准。
