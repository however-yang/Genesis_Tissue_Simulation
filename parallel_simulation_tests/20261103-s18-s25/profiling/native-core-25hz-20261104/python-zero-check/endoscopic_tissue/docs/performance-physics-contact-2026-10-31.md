# 物理求解与接触优化实验：2026-10-31

本轮没有找到可保留的新增物理提速。五个候选中，三个完成了正常 CUDA Graph 的 ABBA 计时和完整交互记录；两个编译策略候选在冻结输入比较出现差异后停止。生产物理源码已恢复，默认剪刀 DLL 保持原版。**没有达到 33 Hz，也没有通过降低材料刚度、阻尼、接触精度或求解次数换取速度。**

实验从 `dev` 的 `fafb85a75e43e84de04c7d79e92e38c22c9849c8` 出发。RTX 3090；全肾规则网格 354,200 个节点，121,260 个活动节点，其中材料节点 102,710、可动活动节点 118,660。保持 1 mm 网格、`dt=1/30 s`、3 子步、4 外层迭代、Young 模量 15,000 Pa、Poisson 比 0.25、应变阻尼 0.04 s，以及原有夹持、摩擦、双刃起切和刀背重叠判据。所有完整计时报告的 Settings 都与本轮基线一致。

## 正常执行的测量结果

GPU 任务串行执行。每个性能候选分别与相邻的基线作 ABBA 对照，各次完整 1110 步。录像和细分 CUDA 事件剖析另行运行，不混入正常性能数据。

“主求解”是 `LCS_Step`；“整步”还包含必要读回、表面查询、控制及检查提交，不包含阶段边界的文件压缩、视频录制和渲染。下面不是实时窗口帧率，也不能使用录像的 30 fps 作为实测速度。

每格是两次运行均值。最后一组基线自身的主求解为 44.178 / 44.677 ms，跨越候选的 44.302 / 44.126 ms，不能把平均值约 0.21 ms 的差别算作可靠优化。三个候选的整步均值都没有改善。接触面修复在重复运行间仍有较大变化，因此也不能只选择较快的一次报告。

33 Hz 对应约 30.3 ms/步；当前主求解本身约 44 ms，尚未加上读回、修复与显示成本。上一轮持久化显示缓冲的收益仍保留，本轮没有把它重复计作物理提速。

## 接触等价性与归约检查

第一项在同一冻结物理状态上分别运行原版与候选，比较有效接触记录的全部字节、节点接触次数以及活跃列表成员集合。列表原子追加的顺序不作为差异。74 个状态、1184 对查询、42,059,264 次三角面查询、4703 条有效接触记录均一致。它仍因没有性能收益而被淘汰。

两个编译策略候选分别为 `triangleWitness` 禁止内联，以及保留内联、仅限制内部固定 8 次搜索循环展开。算法公式和循环次数未减少；独立参考核函数使用另行冻结的原始 `triangleWitness`、`traceTriangleBox`，防止参考路径误用候选函数。

- 禁止内联：FindSurface 指令数约 23,344 → 18,760，但寄存器 135 → 184；第 165 步有 2 条接触记录出现权重差异。
- 限制循环展开：第 435 步有 3 条接触记录出现权重差异。

两者的首次差异都位于 `weight[0]`，接触数量、节点接触次数和列表成员当时一致。这不足以证明视觉退化，但已不能按逐位等价优化直接接纳。因此停止扩展测试，未宣称完成它们的全程视频、性能或真实性验证。

另用完全原版实现对冻结参考作控制实验：完整 1110 步、74 个状态、1184 对查询、42,073,600 次三角面查询、4763 条有效记录均无差异。比较器自身的原版对原版自检通过。

两个物理归约候选各进行了 16 轮 × 6 类目标分布的精确求和压力检查：累计 100,663,296 个线程贡献，9 个梯度/刚度分量与 CPU 整数精确和一致。覆盖单目标、混合目标、稀疏 warp、空块和多个组织分量。该检查验证归约不丢项、不混合分量，**不是完整非线性物理轨迹逐位一致的证明**；浮点累加顺序变化仍须结合重复交互检查。

审查以分阶段时序抽帧及每步肿瘤、肾体、残端的质心、RMS/99 分位速度、相对质心速度、钳口开度和载荷为依据。检查夹紧处的压缩、提拉的局部传递、两次双刃挤压、切断后的回缩及取出，不仅检查“能否变形”。

第一项的提拉及整体运动趋势接近，切割时仍有局部差异。归约地址选举候选在第二剪后约 26 s 出现额外局部速度峰，该次第二剪压缩记录为 5.11 mm，本次基线为 2.21 mm；不能将单次视频近似视为交互等价。该候选本来就没有可靠提速，因此没有采用。

两阶段归约候选也保持了夹持、提拉和两次断裂，但第二剪阶段钳口峰值开度为 5.44 mm，本次基线为 2.68 mm，局部压缩/反力响应并非逐帧一致。该差异尚未通过多次运动记录与基线随机波动分离；在没有可靠性能收益的情况下，不为它放宽效果要求，也不采用它。两个物理归约候选都没有被宣称“交互效果不降”。

基线仍有额外表皮切边和暂时的裂尖非流形边问题，完整肾脏质量验收仍为失败。沿用已有开发入口记录实际裂尖计数以完成全程，最终质量失败仍保留；生产验收线没有放宽。基线一致性不能代替真实手术视频或组织实验标定，也未据此声称临床真实性已得到验证。
