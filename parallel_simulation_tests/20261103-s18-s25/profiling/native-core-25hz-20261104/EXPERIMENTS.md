# 实验记录

全部在独立目录，不修改正式版本；A100 GPU 1 预约独占并监控，仿真亲和性 7,19,20,25，编译仅 30,31 两核。所有参数沿用基线。

## Lean V1

延后构造接触输出，用只读引用替代保留接触的整条临时复制。完整 1410 帧同输入对照：接触/流形/粗层缓存无差异，局部物理检查通过；原有 330 个 GPU 函数 SASS 无变化。

完整 RGB-D 初筛同一库、core=0/1：43.5768 / 43.6700 ms，22.9480 / 22.8990 Hz。没有端到端收益，不单独推荐。编译栈和寄存器改善不是性能改善的证据。

## Tool V2

把器械接触力/Hessian 的求值从单 warp 移到全设备线程，再以原先 32 lane 的遍历顺序求和，四自由度求解不变。额外支持引用 surface stencils 的 query。诊断分别对照每项力/Hessian 和最终整个 CoupledTool 对象。

## Query V3

胶囊查询绕过只供盒体分支使用的 retainedPlane/cache 运算，保留原 preload 与 CCD；在三角形 witness 的迭代间复用相同点的 SDF 法线。分别编译自由寄存器与 launch-bounds 的版本，同输入比对通过后才测性能。

## 已记录的 V3 回归

`query-v3-mode10-full-validation` 在 frame 794（第二次切割）停止，非流形边=1；实际比较到的接触记录、流形与 coarse 系数为零差异，仍不算通过完整验证。该版不保留。SASS 审计发现寄存器约束模板使 18 个原函数编译产物变化，因此 V4 单独移除该限制；不把这种变化武断认作拓扑失败的已证实原因。

## Coarse V5

以 V2 为基础，CTA 全体目标一致时用 ballot/shuffle 选出与原 CAS 必然一致的唯一组件指针；浮点 warp 归约与共享和保留原结构。混合组件 CTA 完整回退原代码。全空 CTA 不做无效加法。带诊断的同一生产内核记录实际 CTA 分布并继续逐项核查原始 coarse 系数，不减求解预算。

## 后续排除与保留范围

- V4（无 launch-bounds）原 330 个函数 SASS 全一致，同输入接触/流形无差异，但仍在第二次切割触发非流形边；不保留查询改写。
- V5 GPU 窗口：coarse 原子优化 3.852 ms/帧，器械预计算版原路径 3.838 ms/帧，未显示计算收益；不保留。不能以 CTA 分布或理论原子争用代替实测速率。
- CPU 无接触提前确认：241 组返回值逐项一致；真实切割表面原法 2.211–2.222 ms，新法 2.317–2.324 ms，回退开销更大；不保留。最初 Numba 混合类型编译错误已修复并保留日志。
- V6 材料分支：对比到停止点的系数零差异，但 frame 792 非流形边=1；拒绝该分支。不据此宣称数学公式改变，而是确认只做局部系数对照不足以保证完整交互回归。
- GPU 器械体检查：241 组随机/实际/退化表面，181 组真实正接触；最大数值差 3.207e-8 native cm，即 3.207e-10 m。与原物理力计算完全分离；接近原检查阈值时回退 CPU。完整回归仍单独进行。

阶段性 V7（后续组合复测失败，不作为最终启用版本）删除未保留的 lean 查询与材料分支，只保留原查询/形变/切割求解、已验证的并行器械求值、只读 GPU 器械体检查。开关默认关闭，不替换正式版本。


## 最终选择：V8 仅保留只读 GPU 检查

V7 在普通完整 RGB-D 首轮 1410 帧通过，复测 frame 792 非流形边=1，已排除器械求值改写，不以首轮 23.47 Hz 宣称通过。V8 从原 N 基线重新复制，只增加 GPU 当前表面检查；形变、接触、夹取、切割代码和全部原 330 个函数机器码一致。

V8 含渲染/CPU 对照的完整 1410 帧验证通过；另做 A–B–B–A 四次完整 1410 帧，全部本地检查通过。当前同库基线 22.12 Hz，V8 23.65 Hz；P95 50.37 ms，最慢 20 帧 18.42 Hz，稳定 25 Hz 未达标。GPU 正接触、实际 RGB-D、首次诊断分配/重复诊断的存档不变性、快照恢复、无渲染检查均通过。

全部正确性、性能口径和仍未通过的物理域项目以 `REPORT.md` 和 `delivery/manifest.json` 为准。
