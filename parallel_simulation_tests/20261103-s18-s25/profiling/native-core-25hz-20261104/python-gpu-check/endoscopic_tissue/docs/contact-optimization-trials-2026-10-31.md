## 2. 实际实现与数值检查

### 腕部查询

只修改剪刀非切割腕部kind=5的新接触最近点搜索，复用项目已有有限线段—三角形解析算法。退化三角形、近乎平行、零长度轴、轴上法向不唯一和非法结果回退原算法；腕部不传bladePhase，不引入刀刃预载或切割逻辑。两个变体分别测试直接内联与专用核函数，不叠加其他候选。

1698组真实CUDA helper测试覆盖随机几何及退化情况。42组指定回退案例均逐位保留基线；866组输出坐标改变，832组与基线相同（后者不等同于实际回退次数）。仅在866组改变案例中，对独立双精度约束最小二乘参考的最大距离误差为3.497e-7 cm，即3.497e-6 mm。解析几何测试通过不代表接触力、切割时序或交互动态已通过。

初版FindSurface编译资源从135寄存器/1872字节栈变为181/2104；专用版普通核保持135/1872，腕部为135/864。这是编译资源观察，不将寄存器数单独当作性能变化的因果证明。源代码与复现说明见[腕部实验](D:/Simulation/genesis-world/endoscopic_tissue_backups/2026-10-31-wrist-opt/README.md)。

### 共享前端与批量候选

线程块共享版本只共享本次调用的器械形状和保守扫掠界，不跨位置、姿态或拓扑变化复用。批量版本一次读入三角面扫掠范围，判断多个剪刀部件；每次调用重新构造器械界，候选容量覆盖全部表面，不设置数量上限，不丢弃普通AABB外的持续刀刃预载。现有身份、接触缓存、摩擦与流形响应保留。

有界grid-stride初版将查询体抽成force-inline函数，冻结输入检查在第二剪附近发现接触权重差异。加密取样后保存了精确输入：kind=5、triangle=30072、weight[0]由0.0504300036变为0.0504295416，接触数量没有变化。相同输入在普通包装、直接候选窄阶段、完整批处理三条路径均复现，定位到查询重构带来的数值变化；未证明具体由哪一条浮点指令导致，不能归因成粗筛漏接触，也不能因差异小就忽略。

随后恢复原核函数体，只增加候选索引入口，精确输入的三条路径均恢复0差异。两个后续版本分别使用连续索引和跨块分散索引。**它们仍按完整表面规模启动窄阶段，并没有实现最终合格的有界工作队列。** 这是修复数值差异后的保守实验，不把它包装成原计划全部实现。

## 4. 异常基线没有用来制造加速

连续索引ABBA的最后一次基线在第二剪以后变慢：incise_2核心均值151.30 ms，后续阶段约210–220 ms；这次整体99.572 ms保留在证据中，不与正常基线混合计算加速比。

新增独立诊断DLL只在CPU端统计已有loaded/free/recovery图选择，不添加GPU查询或改变选择条件；若连续出现慢步才触发既有分段计时。一次完整1110步复测中loaded=1721、free=1609、recovery=0，最大核心调用64.46 ms，未触发分段计时。因此慢段未复现，原因仍未确认；没有证据将先前异常归因于恢复图、GPU占用或温控。随后分散索引的两次正常基线约43 ms，独立报告这一组结果。

## 5. 联合粗模态为什么仍需独立实现

进一步核对[四模态循环](D:/Simulation/genesis-world/endoscopic_tissue/native/vendor/cuda/xpbd/xpbd_solver.cu:3234)后，不能把它简单折成“合并四个核函数”：

1. 四次原更新顺序执行，后一个模态的权重、安全分组和材料线性化读取前一次更新后的状态。一次联合线性化会改变有限迭代下的动力响应，尤其是局部夹痕、钳口平衡和双刃载荷。
2. 四个3维块各有6个独立对称Hessian项，共24项；完整12维对称块有78项，其中54项是跨模态耦合。遍历可以共享，但组装/归约成本会增加，不能据“四趟变一趟”预估四倍加速。
3. 当前单模态体积界使用秩一位移下的一次det表达式。联合位移一般需要三次det沿整个步长区间的可行性检查，包括内部驻点及浮点位置舍入。
4. [pressureLineActive](D:/Simulation/genesis-world/endoscopic_tissue/native/vendor/cuda/solver/material/pressure_patch_line.cuh:7)在mode1–4且已有grips时不激活，并要求没有secondary剪刀接触。它不能直接作为联合方向在夹持、切割阶段的通用能量认证。

所以第三项仍需要完整交叉曲率、同一目标下的接触/锚点/材料能量检查、三次体积界及独立回退路径。保留原局部细网格求解和各切断分量的独立性。这里记录实现前必须解决的具体缺口，不声称12维求解器已实现或能够保证33 Hz，也不将未验证的近似接入默认交互。
