# 训练前基础模块设计与边界

依据用户明确要求采用的《仿真器训练前功能与优化清单》（2026-10-31），本轮先实现第一批接口及第二批的可审计记录基础。新增模块复用当前NativeTissue，默认运行入口、材料、摩擦、接触、断裂及DLL不变。S11以及曲刃几何对应的缺口仍独立保留。接口工作不授予物理可信性或训练准入资格。

考虑过直接改生产入口、重写原生会话，以及增加独立适配层。采用第三种：可比较同一组实际原生命令，且新采集器的记录/检查成本不会进入现有交互默认路径。

环境配置显式固定DLL路径与SHA-256、场景、材料/接触参数、准备过程、11维动作边界/速率和每步控制时间。坐标轴沿用原生世界坐标，长度转为米、角度转为弧度，夹持器方向维持原来的固定值。策略提交绝对目标，适配层记录原始目标、限幅/限速后的目标、drive_command处理后的命令以及实际观测位姿。标准策略不能修改碰撞、接触模型和切断规则。初版一步只执行一个原生dt，不增加原生子步或更换算法。

reset通过销毁并重建原生会话实现。准备可为原场景的重力稳定段、已经夹持的lift段，或夹持后第一次blade_approach段（cut_ready）；准备过程中保留命令、载荷、质量和实际计时。wall的第一次进刀早于夹取，不能用于cut_ready。初始状态只有通过已实现的检查后才返回。每个回合使用独立ID，所有随机采样用显式seed；不承诺CUDA逐位确定性。初版训练示例只采用辅助夹持的局部任务，不容许用省略释放来宣称完整任务修复。

状态保留稳定网格节点ID、材料/辅助/固定掩码、位置、估计速度、连接/断边位置、工具实际位姿、两条求解刃缘、载荷和断裂计数。位置差分速度明确标为估计值；内部摩擦和挤压历史未完整导出，因此状态明确标为部分可观测，连续动作/观测历史可读。不同拓扑版本存单独完整连接与切断分数；每个状态引用对应版本，避免每步重复大邻接表。

记录器保存s0及每步的(before, action, after)，用有界后台写入、独立数组快照和落盘确认；阻塞和记录耗时单列，禁止静默丢帧。异常原始现场及最后可靠状态单列，回合结束类型区分数值失败、越出声明范围、时间上限和正常任务失败。读取器检查连续性、配置和拓扑版本，禁止跨reset/缺帧/异常窗口；未完成动作域验证的记录默认不能作为已批准训练数据。

质量检查复用现有有限值、体积、刀体/腕部重叠、工作区、断边不可恢复及禁切不新增判据；用材料连通分量检测本轮范围以外的完全游离块。范围拦截不等于碎片碰撞修复。表面拓扑与工具几何的检查成本独立计量；未实现的严格曲刃逐点误差、内部求解残差和自由碎片连续相交不能标为通过。

验证顺序是独立CPU数据/边界测试、真实原生reset和小批采集、同命令的完整原生与适配回放、完整视频和独立计时。测试先以同一DLL和配置对照，变化仅为适配/记录层；任何物理差异或性能成本都保留原始结果。批采只验证采集链，S07的充分重复/动作域与材料标定、S08奖励、S10纯摩擦换抓、S11自由释放、S12视觉、S14机器人控制不得自动记为完成。
