## 缺陷来源与仍未完成的问题

只读原生索引溯源复现了切壁与外表面四面共边：同一边有2个皮肤面和2个切壁面，直接使用原生特征点索引，不依赖位置焊接。第一剪的失败边连接相邻体素 `[52,62,18]` 与 `[53,62,18]`，两者掩码160、全部8角仍属同一个连通分量。它是共享体素面的边界路径合并，不是切壁扇形三角化内部对角线。R25已在上述冻结输入和完整参考轨迹中解决这一缺陷；其他薄壁、短刀程及多次重抓仍需各自验证，不能推广为任意切割均无缺陷。

本地《Manifold Dual Contouring》所述边界循环区分提供了方向。当前有限剪切可以在体素面内部结束，现有切边掩码并不完整表达内部裂纹前沿，因此R25只针对已验证的非材料角点连接问题保留真实交点分组；没有宣称完整实现该论文算法，也没有扩大剪切范围或把切口拉直。

`stray_skin_cuts` 是旧测试的参考区域诊断。用户已明确切口应跟随实际两个切缘交叉处与变形组织的接触，允许弯曲；因此不能仅因偏离静止组织上的预设区域就认定切错，更不能为了清零该计数强制直线切口。该诊断需与实际剪刀切缘/扫掠证据一起复核，暂不删除也不单独作为真实切割错误的结论。

薄壁短刀程残连与真实补剪，以及深咬合/重抓的弱摩擦夹取继续保留为未完成项。已有力诊断显示局部滑动饱和，但总切向力小于总摩擦容量不能证明每个接触点都可静止；满足摩擦锥也不能单独证明滑脱真实。没有增加摩擦系数、隐藏夹持点或删除真实残连来绕过验证。本轮尚未将新的摩擦或切割算法叠加到释放候选。
