# 联合粗模态独立实验：实现、耗时与交互对照

本轮在 dev `0403d319097ca77099edc5c33d51b2d22d4312a0` 上实现了两个独立版本，完成两组正常 CUDA Graph ABBA 计时、三段真实状态录像和两段完整并排对照。**尚未达到 33 Hz；两个候选都没有通过采用条件，未替换默认版本。**

第一版把原四次粗修正合并为含完整交叉项的 12 维联合系统；第二版只进一步跳过无需回退时的旧粗层空遍历。第一版核心耗时增加 11.94%，第二版增加 9.67%。夹持数量、双刃载荷及残端运动也有差异，不能声称保持了当前交互效果。

完整源码、独立补丁、检查器及复现说明见[实验目录 README](D:/Simulation/genesis-world/endoscopic_tissue_backups/2026-10-31-joint-coarse/README.md)。本文数据来自[重新核验生成的摘要](D:/Simulation/genesis-world/endoscopic_tissue_backups/2026-10-31-joint-coarse/evidence-summary.json)。本轮是前一份[模块分析](D:/Simulation/genesis-world/endoscopic_tissue/docs/module-optimization-analysis-2026-10-31.md)中联合粗模态假设的实际实现，不是对相关论文的完整复现。

## 1. 不变的条件

RTX 3090，驱动 591.86，CUDA 12.5。每次完整肾脏双器械流程均为 1110 步，121260 个活动节点、102710 个材料节点、118660 个可动活动节点。总格点 354200 包含非材料区域，不能拿来冒充材料节点数量。

网格 1 mm，E=15000 Pa，ν=0.25，strain damping=0.04 s，dt=1/30 s，每步 3 个子步、每子步 4 次外迭代。没有减少细层自由度、材料 CG、接触细化、CCD 或切割拓扑更新，也没有调整材料、摩擦、夹持和双刃断裂参数。所有质量阈值保持原样。

两个候选分别编译到 bin-joint-coarse31-guarded 与 bin-joint-coarse31-gated，诊断版另有 probe 目录。生产 CUDA 源最终恢复到起点，默认剪刀和单刀 DLL 从未覆盖。

## 2. 联合系统实际做了什么

复用现有四个标量粗模态，每个模态三个位移分量，按切断后的组织连通分量形成 12 维系统。夹持区域保留现有平滑衰减尾部，游离分量保留原来的常量/仿射基；同一快照下建立近体积界的安全分组，并一致地平均四个权重。细网格仍完整参与后续求解，没有把整块组织改为刚体或仅保留粗模态。

联合组装包含 12 个梯度和 78 个对称曲率项，保留跨模态耦合，以及原材料、客观黏性、拉伸硬化、惯性、支持、夹持锚点与接触贡献。曲率是正半定 GN 搜索近似，省略可能不定的混合二阶 det 项，不能称为完整精确 Hessian。小系统采用双精度 Cholesky、对角缩放及相对 1e-7 的搜索系统正则；没有修改材料刚度。

联合方向沿步长的 det 通常是三次式，因此检查整个区间及其驻点，不能复用单模态的线性体积界。接触特征闭合界保持原定义。线搜索检查最大可行步的 1、1/2、1/4、1/8，使用实际舍入位移计算原材料等增量；摩擦压力和法向在试探中滞后固定。它是当前接触线性化下的耗散接受检查，**不是全系统保守势能，也不是真实性证明**。

只替代 it=0 的四次粗修正；it=2 保留。未接受的组织分量执行原四次修正；跨组织分量的接触/锚点见证会禁用相关联合块并回退。零梯度情况接受零步以避免无效回退。第二版增加 GPU 标记：所有分量接受时，原四次回退核函数在入口统一退出；有失败分量时仍执行原函数体。16 个包装函数去除入口条件和新增参数后，与对应原函数逐字一致，已重新核验。

## 3. 浮点体积问题的红/绿回归

最初版在完整诊断中出现 70 个约 1e-7 量级的负体积余量，最小 -1.1525e-7；旧 diagnostic 的 2e-5 告警容差没有报警。随后增加“任何负余量都失败”的严格检查，旧 DLL 明确在 step262 失败，余量 -2.7939677e-8。没有降低要求将它算作通过。

独立合成输入定位到多项式路径判定与真实浮点存储端点之间的缝隙：12000 个 CUDA 用例中，旧判定接受 704 个实际端点低于下界的案例。新版本保留三次路径检查，额外一次性生成试探坐标，使用同一个不内联 det 例程认证真实存储端点和闭合界；通过后直接复制已认证坐标写回，失败则回退。新判定在相同 12000 个用例中错误接受 0 个。

## 6. 成本定位与下一步边界

第二版实际编译资源显示：联合组装 k_JointAccumulate 使用 255 个寄存器、480 字节栈；联合小系统求解使用 254 个寄存器、1264 字节栈；线搜索使用 123 个寄存器、144 字节栈。来源为[kernel-resources.json](D:/Simulation/genesis-world/endoscopic_tissue_backups/2026-10-31-joint-coarse/kernel-resources.json)。它提示单线程同时维护 90 个累计项的成本，不能单凭静态资源宣称测得了低占用率或证明了全部慢因。

正常计时与录像结束后，另行串行运行基线和第二版各 1110 步的模块诊断。结果见[sections-summary.json](D:/Simulation/genesis-world/endoscopic_tissue_backups/2026-10-31-joint-coarse/sections-summary.json)：

|模块诊断，ms/步|基线|第二版|
|---|---:|---:|
|粗模态段（联合求解、安全检查及旧回退均计入）|4.225|8.164|
|局部顶点更新|5.684|5.737|
|材料 CG 迭代|5.357|5.383|
|主循环接触发现|4.816|4.899|
|子步前工具、接触发现与流形|2.507|3.125|

最大的模块增量为粗模态段，约 +3.94 ms，与普通 Graph 下的变慢方向一致。它包含联合组装、求解、线搜索、端点认证和回退，当前没有将这些子项进一步隔离，因此不能把全部成本归到寄存器或某个核函数。此次诊断关闭 CUDA Graph，事件时间包含启动间隙，且基线与候选轨迹不同、各只有一次；只用于定位模块，不能代替正常运行帧率。CG 总组装与其子项有重叠，不能将所有诊断字段直接累加成新的总耗时。

旧粗模态在本次诊断中只有约 4.2 ms，而普通核心距离 30.3 ms 预算仍差约 13.5 ms。这提示只优化粗层很难独立实现 33 Hz；后续仍需要同时减少细层材料和接触的实际成本。上述跨测量口径比较只说明规模，不能视为严格的速度上界。

下一次若继续该路线，优先研究线程束协作的交叉项组装和分块归约，减少每线程长期存活的数据，同时保留全部交叉项、实际端点认证与回退。首先需要冻结输入下的梯度/曲率/接受决策对照，再做同样的整段动态与普通 Graph ABBA。不能为省成本删掉体积路径、接触守护，或退回把 3×3 块拼成无耦合对角矩阵；也不把减少迭代/增加阻尼作为本实现的补救。

## 7. 保护与结论

本轮两项实验没有通过性能初筛，交互也不足以证明不降低，因此未进入肾脏≥6、墙面≥10、组织瓣≥10、单刀≥1的采用级重复。它们保存为可复现实验，不作为默认配置。

归档核验覆盖八次完整计时、三段实际录像、两段并排视频、两个完整严格绿色回归、旧严格失败证据、六份可独立应用补丁和 16 个原核函数体的一致性。默认剪刀 SHA256 为 `0d09f56a1f4acb813424cd1dee3233d89ce7ef5c0d45e64f079c7d7387912225`，单刀为 `2632a926b385d9c9a81d5f7d7ebb75fe0501917a9cf83d0c19d3a29c62af961b`；生产 native 相对起点无改动。

联合粗模态已经实际实现并测试，但这个实现目前既没有提速，也没有通过交互采用验证。33 Hz 仍是未达成目标。
