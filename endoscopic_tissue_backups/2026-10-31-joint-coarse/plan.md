# 联合粗模态独立实验

起点dev 0403d319097ca77099edc5c33d51b2d22d4312a0。用户已授权本方案独立实现，未验证不替换默认。

1. 复用mode1–4的四个标量基，每组织分量12维，完整78个对称曲率项。保留GN正定曲率和原目标梯度；不把不同模态拼为对角块。
2. 同一快照一次建立近体积界安全分组，对四组权重作一致分组平均；不跨切断分量。
3. 联合步沿三次det路径检查，检查舍入后的实际位移。保持原接触特征闭合界；更新需降低材料/惯性/支持/锚点及固定接触线性化下的耗散增量目标。摩擦压力在试探线搜索内滞后固定，不能将非保守摩擦包装为完整全局保守势能。
4. 候选仅替代it=0的四次粗修正；失败分量回退原四次，it=2、顶点、材料CG、工具耦合、CCD、拓扑与迭代预算不变。接触见证跨分量时禁用联合步并回退。
5. 先数值验证梯度、跨块GN曲率、三次路径与线搜索/回退，然后正常Graph ABBA各1110步。录像与计时分开，基线和候选各1111真实状态，检查完整对照及运动/双刃载荷曲线。
6. 只有通过性能与交互筛选才做采用级多场景重复；否则保留补丁/证据、恢复基线、不替换默认。

默认剪刀与单刀DLL均不覆盖。构建显式使用bin-joint-coarse31等独立输出目录。

完成记录：上述独立实现、数值红/绿检查、两组 ABBA 与完整录像对照已完成；两个候选均无性能收益且未证明交互不降，按第6项保留实验、默认不替换。详见同目录 README 和主报告。
